### 5.4 app/graph/（业务核心）

**流转总图（V1.1：无 interrupt，结论二态）**：

```
START → input_parser
  ├─(need_guidance: 缺图/无工件号且无法纠正)→ END（填报指引，不落库）
  ├─(request_review)→ review_request → END
  ├─(new_inspection: 有图+已登记工件)→ cv_engine → standard_validator
  │      ├─(超标/可疑/有notice)→ rag_retrieval → reasoning → self_reflection
  │      │        └─(不过且 retries<2)→ reasoning（循环）
  │      └─(完全合格)→ reasoning
  │      reasoning → self_reflection → report_generator → END
  └─(其他)→ qa_answer → END
```

| 文件 | 职责 |
| --- | --- |
| `state.py` | AgentState：`messages`(add_messages) + 业务快照；**`inspection_uid`**（每轮独立单据）、**`validator_notice`**（比对阶段用户提示）、`suspects` |
| `edges.py` | `route_after_parse` 四向（inspect 必须图+登记工件）；`route_after_validate`（超标/可疑/notice→retrieval；合格→reason）；`route_after_reflection`（regen 循环上限 2） |
| `builder.py` | 9 节点 + 条件边 + compile |

**nodes/**：

| 节点 | 职责 | 调试要点 |
| --- | --- | --- |
| `input_parser.py` | 意图（LLM 结构化，失败降级规则，五值含 request_review/need_guidance）；**工件三级解析**：精确→名称匹配（base_name 去尾代号）→相似度≥0.8 笔误纠正（difflib）；失败回指引**直接 END 不落库** | `resolve_workpiece()` 可独立调试 |
| `cv_engine.py` | 调 CVProvider；**单据在此创建**（按 inspection_uid，工件号已校验） | 契约校验失败→SSE error |
| `standard_validator.py` | `compute_gaps` 比对；**无标准+有检出→fail+notice；低置信度→fail+notice**（保守判定，不阻断） | compute_gaps 纯函数有单测 |
| `rag_retrieval.py` | 按超标/可疑类型检索；失败不阻断（docs=[]） | |
| `reasoning.py` | LLM 结构化 ReasoningReport；facts 含 validator_notice/rag_docs；失败重试 2 次→保守 fail；LLMAuthError 透传 | Prompt 在 prompts/reasoning.py（**铁律 8：rag_docs 空时禁编参数+末尾标注未参考 RAG**） |
| `self_reflection.py` | 5 硬规则：R1（fail 需 gaps **或 suspects**）/R2 建议缺陷⊆超标/R3 参数在范围表或文档正文/R4 数值溯源（白名单含检出数/类型数/模型名/尺寸/meta/批次号/可疑项 conf，5% 容差）/R5 禁模糊词；超限强制 fail | `run_hard_rules` 纯函数有单测 |
| `report_generator.py` | 收口：补最小报告；notice 去重（**已在正文则不追加**，防回放变多）；无 RAG 追加"未参考知识库"提示；报告入 MinIO（失败不阻断）；按 uid 落库；展示消息 | `render_report_markdown` 五节模板 |
| `review_request.py` | 对话申请复核：定位本人记录（last_inspection_id 优先/工件号最近）→建单→回执 | 建单逻辑在 services/review.create_request |
| `qa_answer.py` | 问答：快照+RAG 上下文；**操作工剔除参数**；失败兜底 | |

### 7.4 已知坑（改前必读）

1. 异步必须 **AsyncRedisSaver**（同步版无 astream 方法）；
2. RediSearch 只能 **DB0**；
3. ORM 时间列必须 `DateTime(timezone=True)`；
4. ini 文件中文注释在 GBK 崩溃（保持 ASCII）；
5. passlib 锁 `bcrypt<4.1`；
6. LLM 401/403 快速失败——查 key 与 BASE_URL 匹配，勿加重试；
7. 评测/冒烟按 Mock LLM 校准，跑前加 `CV_MOCK_MODE=match LLM_PROVIDER=mock` 前缀；smoke 打测试实例需 `QC_BASE`；
8. Vite 热更新偶发失效：重启 dev（必要时 `--force`）；
9. **FastAPI 路由顺序**：`/inspections/database` 必须注册在 `/{inspection_id}` 之前，否则被路径参数吞掉；
10. `DISTINCT ON` SQL 的 WHERE 只能引用外层别名（latest/g/w）；
11. 后台起的 uvicorn 退出了子进程可能还占端口：`netstat -ano | findstr :端口` 找 PID 杀。
